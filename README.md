# ПМУ — лабораторные работы

Учебный Flutter-проект по дисциплине ПМУ.

- **Студент:** Кирюшин А.П.
- **Группа:** ПИбд-32

## Лабораторные работы

| № | Ветка | Что сделано |
|---|-------|-------------|
| 1 | `lab1` | Flutter-проект собран и запущен на Android; ФИО и группа выведены в AppBar |
| 2 | `lab2` | Dart: классы, enum, циклы, generics, анонимные функции, `Future` и `extension` |
| 3 | `lab3` | Список карточек: картинка и текст, всё в `lib/main.dart` |
| 4 | `lab4` | Лайки, SnackBar и экран с деталями — тоже в `lib/main.dart` |

## Запуск

```bash
flutter pub get
flutter run
```

Для запуска на Android нужен эмулятор или подключённое устройство:

```bash
flutter emulators --launch Medium_Phone_API_37.0
flutter run -d emulator-5554
```

## Лабораторная 4

Всё написано в одном файле `lib/main.dart`:

- у каждой карточки есть кнопка-сердечко;
- при нажатии меняется иконка и появляется `SnackBar`;
- при нажатии на карточку открывается экран с деталями.

Запуск на эмуляторе Android:

```bash
flutter run -d emulator-5554
```
