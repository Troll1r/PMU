# ПМУ — лабораторные работы

Учебный Flutter-проект по дисциплине ПМУ.

- **Студент:** Кирюшин А.П.
- **Группа:** ПИбд-32

## Лабораторные работы

| № | Ветка | Что сделано |
|---|-------|-------------|
| 1 | `lab1` | Flutter-проект собран и запущен на Android; ФИО и группа выведены в AppBar |
| 2 | `lab2` | Dart: классы, enum, циклы, generics, анонимные функции, `Future` и `extension` |
| 3 | `lab3` | Книги в карточках как в лекции: оранжевые, с картинкой, текстом и иконкой |

## Запуск

```bash
flutter pub get
flutter run
```

Для запуска на Android нужен эмулятор или подключённое устройство:

```bash
flutter emulators --launch Medium_Phone_API_37.0
flutter run -d emulator-5554
```

## Лабораторная 3

Всё написано в одном файле `lib/main.dart`, как в лекции:

- оранжевый `AppBar` с текстом «Flutter is gorgeous»;
- три оранжевые карточки с книгами;
- в каждой карточке картинка, заголовок, автор и иконка;
- картинки лежат в `assets/images` (в лекции они грузятся по URL,
  здесь — локально, чтобы работало без интернета).

Запуск на эмуляторе Android:

```bash
flutter run -d emulator-5554
```
